# Career Copilot frontend

React, TypeScript and Vite (ADR 0020). Requires Node.js 26 (see `.nvmrc`).

From the repo root:

    just web-install   # install the packages exactly as locked
    just web           # run the app with hot reload at http://localhost:5173
    just web-check     # fix, format, lint, check types and build

Biome lints and formats the code (`biome.json`).
